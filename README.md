# Profil Mahasiswa (UTS Pemrograman Mobile 2)

Setup:
1. `flutter create .` di dalam folder ini (menghasilkan folder android/ios/web, dll.; file lib/ dan pubspec.yaml tidak ditimpa)
2. `flutter pub get`
3. Edit data diri di `lib/pages/profil_page.dart` (objek `profile`)
4. (Opsional) taruh foto di `assets/foto.jpg`, lalu hapus tanda `#` pada bagian assets di `pubspec.yaml`
5. `flutter run`
